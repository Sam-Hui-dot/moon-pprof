# Validation Scope and Source Accounting

## Verification Matrix

1. **Multi-target unit tests (`moon test --deny-warn`)**
   - Covered targets: `wasm`, `wasm-gc`, `js`, `native`.
   - `decoder_test.mbt`: binary `.pb` and gzip `.pb.gz` round-trip encoding/decoding, empty input rejection, corrupted gzip stream rejection, truncated varint rejection, and `profile.proto` invariant checks (`string_table[0] == ""`, sample value arity).
   - `analysis_test.mbt`: leaf-first inlined frame expansion (`Location.lines`), recursive stack deduplication for cumulative (`cum`) attribution, explicit vs default `sample_type` selection, and deterministic Brendan Gregg folded stack collapse.
   - `diff_test.mbt`: absolute vs duration-normalized (`--normalize`) comparisons, `regressed`/`improved`/`added`/`removed`/`unchanged` classifications, and CI gate policy violations returning exit code `1`.
   - `flamegraph_test.mbt`: single-profile SVG, Top-Down Icicle vs Bottom-Up Flame layout (`icicle~`), `visible_tree_depth` sub-pixel pruning height compaction, Brendan Gregg red/blue differential SVG legend & delta metadata, self-contained interactive HTML, and Markdown reports.
   - `merge_test.mbt`: multi-profile string-table remapping, function/location deduplication, coalesced sample totals, `Sample.label` slicing & grouping, and `focus`/`ignore`/`hide` filters.
   - `callgraph_test.mbt`: weighted directed callgraph construction, DFS cycle back-edge detection, topological layering, Sugiyama barycenter ordering, native SVG/DOT rendering, and differential callgraph highlighting.
   - `peek_test.mbt`: `go tool pprof -peek` style callers/callees attribution, text/Markdown output, and multi-metric interactive HTML rendering.
   - `ingest_test.mbt`: V8 `.cpuprofile` call-tree & `timeDeltas` ingestion, V8 `.heapprofile` allocation tree & sample ingestion, MoonBit JS symbol demangling, Linux `perf script` parsing, Brendan Gregg `folded` ingestion, and 6-format auto-detection (`detect_profile_format` / `decode_any_profile`).
   - `prune_test.mbt`: `FilterSpec` (`focus`/`ignore`/`hide`/`label`) profile pruning, dead-symbol garbage collection, string-table compaction, and `.pb.gz` round-trip verification.
   - `lines_test.mbt`: source-line `flat`/`cum` aggregation (`compute_line_hotspots`), annotated source rendering (`render_annotated_source`), and top critical paths (`compute_traces`).
   - `trend_test.mbt`: multi-version revision series (`compute_trend`), regression inflection alert detection, native multi-series SVG line chart (`render_trend_svg`), and Markdown/text rendering.
   - `fuzz_test.mbt`: 256 deterministic pseudo-random malformed inputs (including gzip-prefixed garbage) and all truncated prefixes of valid `.pb` and `.pb.gz` streams verifying panic-free error handling.

2. **Official `go tool pprof` oracle cross-check (`demo/verify_oracle.py`)**
   - Real `.pb.gz` CPU and Heap profiles generated by `demo/gen_go_profiles.go` plus real MoonBit self-profiling V8 `.cpuprofile` (`demo/fixtures/moonbit-self.cpuprofile`) and `.heapprofile` (`demo/fixtures/moonbit-self.heapprofile`).
   - Asserts exact integer equality (0 error) against `go tool pprof` on CPU (`180M` / `490M ns`), Heap `alloc_space` (`3,247,944` / `6,543,480 B`), `merge` vs `-proto` (`670M ns`), `prune` vs `-proto -focus` (`350M ns`), `peek` vs `-peek`, `convert --from v8` (`758,330,000 ns`), and `convert --from v8-heap` (`5,039,760 B`).
   - Verifies `diff --hide runtime.` regression gating (exit code `1`), `trend` 3-version inflection detection & SVG output, `flamegraph --icicle`, `list --source-file` annotated Go source, `traces`, single & differential `callgraph` SVG/DOT outputs, and 4-metric Heap HTML (`--all-metrics`).

3. **Independent consumer, browser bundle & large-scale benchmark checks**
   - CI creates a separate temporary MoonBit module importing `Sam-Hui-dot/moon-pprof@0.5.0` and exercises ingestion (including V8 `.heapprofile`), pruning, encoding, decoding, Icicle SVG, multi-version trend SVG, callgraph, and traces on both `js` and `wasm` targets.
   - CI builds `web/` (`python3 demo/build_web.py`) and runs a Node.js smoke check verifying all 6 formats, MoonBit self CPU & Heap demangling, Top-Down Icicle & Flame toggling, and in-browser `.pb.gz` prune export.
   - CI runs `python3 demo/benchmark.py --quick` (10k samples); full 10k / 50k / 100k Native & JS benchmark results are documented in [docs/BENCHMARK.md](BENCHMARK.md).

## Known Boundaries

- Supports Google `perftools.profiles.Profile` (`profile.proto`) binary `.pb` and RFC 1952 `.pb.gz` streams (unknown protobuf fields are skipped safely).
- Does not disassemble raw binaries or symbolize un-symbolized instruction addresses from external DWARF/ELF files; locations without `Line` metadata are rendered by hexadecimal address (`0x...`).
- Filtering currently uses deterministic substring matching on function name or filename rather than full RE2 regular expressions.

## Source Accounting

Non-test MoonBit source lines are counted across root library files (`*.mbt` excluding `*_test.mbt`) and CLI files (`cmd/main/*.mbt`), excluding blank lines, `//` comment lines, generated `.mbti` files, and `demo/` scripts.
